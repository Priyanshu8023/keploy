# ISSUE-005: Default MongoDB Password Hardcoded in Config

## Summary
`config/default.go` line 60 sets `mongoPassword: "default@123"`. This appears in generated `keploy.yml` files, CI logs, and error messages. Any MongoDB instance accepting this well-known password from the public repo is compromised.

## Suggested Patch
```diff
-  mongoPassword: "default@123"
+  mongoPassword: ""
```

# ISSUE-007: `makeDirectory` Uses 0777 Permissions

## Summary
`utils/utils.go:769` creates directories with `os.MkdirAll(path, 0777)`. On systems where umask is 0 (common in Docker), this creates world-readable/writable directories containing sensitive API traffic data.

## Suggested Patch
```diff
- err := os.MkdirAll(path, 0777)
+ err := os.MkdirAll(path, 0755)
```

## Validation Checklist
- [ ] Fix implemented
- [ ] Verified directory permissions are 755
- [ ] Docker-based tests pass
