# ISSUE-011: Busy-Wait Polling in Mock Correlation

## Summary
`record.go:461-468` uses `time.Sleep(10ms) × 50` busy-wait loop to correlate mock IDs. This burns CPU and has an arbitrary 500ms timeout.

## Suggested Patch
Replace with channel-based notification:
```go
type correlationStore struct {
    mu      sync.Mutex
    store   map[string]models.MockEntry
    waiters map[string]chan models.MockEntry
}

func (cs *correlationStore) Store(key string, entry models.MockEntry) {
    cs.mu.Lock()
    cs.store[key] = entry
    if ch, ok := cs.waiters[key]; ok {
        ch <- entry
        delete(cs.waiters, key)
    }
    cs.mu.Unlock()
}

func (cs *correlationStore) WaitFor(key string, timeout time.Duration) (models.MockEntry, bool) {
    cs.mu.Lock()
    if entry, ok := cs.store[key]; ok {
        cs.mu.Unlock()
        return entry, true
    }
    ch := make(chan models.MockEntry, 1)
    cs.waiters[key] = ch
    cs.mu.Unlock()
    
    select {
    case entry := <-ch:
        return entry, true
    case <-time.After(timeout):
        return models.MockEntry{}, false
    }
}
```

# ISSUE-013: Bare `go func()` Without `errgroup` or Recovery

## Summary
~50 instances of `go func() { ... }()` in production code without `utils.Recover()` or `errgroup` management. Violates the project's own convention (AGENTS.md).

## Suggested Patch
For each bare goroutine, add recovery:
```go
go func() {
    defer utils.Recover(logger)
    // ... existing logic
}()
```
Or migrate to nearest errgroup:
```go
g.Go(func() error {
    defer utils.Recover(logger)
    // ... existing logic
    return nil
})
```

# ISSUE-014: pprof Server Without Authentication

## Summary
`main.go:85` starts `http.ListenAndServe(addr, nil)` when `PPROF_PORT` is set. In Docker/k8s, "localhost" may be accessible from other pods/containers. Pprof endpoints expose goroutine stacks containing database credentials, auth tokens, etc.

## Suggested Patch
```go
if pprofPort := os.Getenv("PPROF_PORT"); pprofPort != "" {
    pprofToken := os.Getenv("PPROF_TOKEN")
    mux := http.NewServeMux()
    mux.HandleFunc("/debug/pprof/", func(w http.ResponseWriter, r *http.Request) {
        if pprofToken != "" && r.Header.Get("Authorization") != "Bearer "+pprofToken {
            http.Error(w, "unauthorized", http.StatusUnauthorized)
            return
        }
        http.DefaultServeMux.ServeHTTP(w, r)
    })
    go func() {
        addr := "localhost:" + pprofPort
        logger.Info("pprof server starting", zap.String("addr", addr))
        if err := http.ListenAndServe(addr, mux); err != nil {
            logger.Error("pprof server failed", zap.Error(err))
        }
    }()
}
```
